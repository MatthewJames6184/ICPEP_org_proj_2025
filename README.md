# ICPEP Organization Website

A comprehensive PHP-based web platform for the Institute of Computer Engineers of the Philippines Student Edition - Bulacan State University (ICpEP.SE - BulSU).

## Overview

This website serves as the digital hub for ICpEP.SE - BulSU, a student organization committed to empowering future computer engineers by bridging the gap between academia and industry. The platform showcases the organization's mission, vision, and objectives while providing essential functionality for member communication, voting systems, and administrative management. Built during the 2025 Electives 1 & 2 coursework, this project demonstrates professional web development practices including responsive design, database integration, and secure backend operations.

## Key Features

### Public Website
- **Organization Information** - Comprehensive details about ICpEP.SE - BulSU's mission, vision, and objectives
- **Responsive Design** - Mobile-friendly interface built with Bootstrap for optimal viewing across all devices
- **Team Showcase** - Display of developer team members with social media integration
- **Contact Form** - Visitor contact system with email notification functionality
- **Navigation Portal** - Easy access to all organizational sections including home, info, objectives, about, and contact

### Administrative Features
- **Voting System** - Comprehensive election management with vote counting and candidate ranking by position
- **Member Login** - Secure authentication system for authorized users to access restricted areas
- **Email Integration** - Automated mailing system for contact form submissions and notifications
- **Database Management** - MySQL backend for storing voting data and organizational records

## Technology Stack

- **Language**: PHP (98.4% of codebase)
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap 4
- **Backend**: PHP with MySQL database
- **Libraries**: 
  - jQuery for DOM manipulation
  - Font Awesome for icons
  - TCPDF for PDF document generation
  - Bootstrap for responsive styling
